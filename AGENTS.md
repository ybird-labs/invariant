# Agent Instructions

- Always use Conventional Commits for commit messages, for example `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`, or `ci: ...`.
- Never add yourself, an AI assistant, or any automation identity as an author, co-author, committer credit, signature, trailer, or attribution in commits, branches, pull requests, issue comments, changelogs, or generated files.
- Do not include lines such as `Co-authored-by`, `Generated with`, `Authored by`, or similar AI/tool attribution unless the human maintainer explicitly asks for it.
